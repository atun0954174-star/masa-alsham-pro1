# ماسة الشام للحوالات المالية

واجهة احترافية ثنائية الاتجاه بصريًا، Mobile First، لشركة ماسة الشام للحوالات المالية.

## ما تم بناؤه

- صفحة رئيسية احترافية وهوية SVG أصلية داخل الموقع.
- الدول: سوريا، مصر، لبنان، تركيا فقط.
- حاسبة حوالات مرتبطة بإعدادات سعر الصرف والعمولة.
- نموذج إرسال حوالة.
- إنشاء رقم طلب فريد بصيغة `MS-XXXXXXXX`.
- تجهيز رسالة WhatsApp إلى `+9647772073950`.
- صفحة تتبع الحوالة وحالات Timeline.
- لوحة إدارة تجريبية للطلبات والأسعار والعمولات.
- صفحات/أقسام الخصوصية والشروط ومكافحة الاحتيال.
- تصميم Responsive للهاتف والتابلت والكمبيوتر.
- لا توجد أسعار صرف أو أرقام ترخيص أو عناوين تفصيلية مخترعة.

## تشغيل سريع

افتح `index.html` مباشرة في المتصفح، أو ارفع محتويات المجلد إلى خدمة استضافة Static.

## لوحة الإدارة التجريبية

افتح `admin.html`.

كلمة مرور التجربة:
`masa2020`

**تحذير:** هذه لوحة تجريبية تعتمد على `localStorage` في المتصفح، وليست نظام إدارة آمنًا للإنتاج. لا تستخدمها لحفظ بيانات عملاء حقيقية.

## قبل الإطلاق الحقيقي

لأن الموقع يتعامل مع بيانات شخصية وطلبات مالية، يجب ربطه بخادم وقاعدة بيانات حقيقية مع:

- Authentication آمن للمدير.
- قاعدة بيانات PostgreSQL/Supabase أو Vercel Postgres.
- API server-side.
- صلاحيات وصول.
- تشفير وحماية الأسرار.
- Rate limiting وCSRF/CORS حسب البنية.
- سجل تدقيق للعمليات.
- نسخ احتياطية.
- سياسات احتفاظ بالبيانات.
- HTTPS على النطاق النهائي.

كما يجب أن تبقى أسعار الصرف والعمولات والبيانات التنظيمية غير المعروفة قابلة للإدارة من الخلفية، لا داخل JavaScript العام.
